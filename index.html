Why AI-Assisted Interviews?

為什麼你需要這個工具？

沒有準備好的候選人，會在壓力下失去邏輯；善用工具的人，會在競爭中拉開差距。

😰

沒有 AI 助力的困境

在高压面试环境中，即使经验丰富的候选人也会因为紧张而影响表现。

  • 听到问题后大脑瞬间空白，反应迟钝
  • STAR 法则记得但现场难以组织完整答案
  • 专业术语卡壳，回答缺乏深度和结构
  • 英语面试时用词不精准，表达不够地道
  • 被追问时慌乱，无法从容延续话题
  • 身体语言和表情在压力下失控
🚀

AI 赋能的面试表现

AI Interview Assistant 将你与顶尖候选人拉开差距，在每一次回答中展现专业与自信。

  • 问题出现 < 2 秒内获得结构化答案提示
  • 实时识别追问意图，提前准备延伸回答
  • 专业术语和案例自动推荐，增加答案深度
  • 英文回答即时优化，用词更地道精准
  • 保持眼神交流，AI 替你记忆要点
  • 多语言支持，面试任何地区都不怕

FAQ

常見問題

有其他問題？歡迎在 GitHub 發 Issue 或聯繫我們。

這個擴充功能是免費的嗎？
是的，基本功能完全免費，永久免費使用。Pro 版本提供進階功能，月費 NT$199，適合有大量面試需求或希望獲得最佳表現的專業候選人。
我的面試音訊會被上傳到伺服器嗎？
不會。所有語音辨識都在本地透過 Chrome 原生的 Web Speech API 處理，音訊資料不會離開你的電腦。我們非常重視隱私，資料僅存儲在瀏覽器本地存儲中，隨時可以清除。
使用時面試官能看到任何東西嗎？
完全不會。AI 產生的答案只會顯示在你自己的螢幕上，是一個浮動覆蓋層。面試官在視訊會議中不會看到任何額外的內容或標記。
需要提供 API Key 才能使用嗎？
基本功能不需要 API Key，可以直接使用。但若要使用 GPT-4o 等模型的高級功能，需要在設定中填入你自己的 API Key（免費版用戶可使用 MiniMax M3 等免費模型）。
支援哪些 AI 模型？
目前支援四種頂級 AI 模型：OpenAI GPT-4o、Google Gemini 1.5 Pro、Anthropic Claude 3.5 Sonnet，以及 MiniMax M3。你可以在設定中自由切換喜歡的模型。
適用於哪些面試平台？
支援 Google Meet、Zoom、Microsoft Teams、Cisco Webex 和 Slack（含 Free 和 Pro 版本）。只要是 Chrome 瀏覽器能正常運行的視訊會議平台，理論上都能使用。
可以離線使用嗎？
語音識別功能需要在有網路的環境下運行（依賴 Chrome 瀏覽器的 Web Speech API）。AI 分析功能需要網路連線才能呼叫 AI 模型 API。
如何安裝這個 Chrome 擴充功能？
很簡單：1) 從 GitHub Releases 頁面下載最新版本的 ZIP 檔；2) 解壓縮到本地資料夾；3) 在 Chrome 輸入 chrome://extensions；4) 開啟「開發者模式」；5) 點擊「載入未封裝項目」並選擇解壓後的資料夾。
